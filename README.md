# 📸 UX Na Lente — Organização inteligente de fotografias

O **UX Na Lente** é um projeto desenvolvido na FIAP, com a ideia de facilitar a organização de fotografias dos celulares **JOVI**.

A proposta surgiu de um problema simples: conforme acumulamos cada vez mais fotos, encontrar, separar e organizar esses arquivos pode se tornar uma tarefa cansativa e demorada.

Pensando nisso, desenvolvemos uma solução que busca **auxiliar o usuário na organização das suas fotografias**, oferecendo recomendações e mantendo a decisão final nas mãos do usuário.

---

## 💡 O projeto

O UX Na Lente foi desenvolvido em diferentes etapas e tecnologias, cada uma com uma função dentro da solução:

### 🐍 Python — Protótipo

Utilizamos Python para desenvolver o **protótipo da lógica da Solução**, simulando o funcionamento da solução e o processo de organização das fotografias.

Nessa etapa trabalhamos conceitos como:

* Funções;
* Listas e dicionários;
* Condicionais;
* Loops;
* Validação de dados;
* Entrada e saída de informações.

### 🌐 HTML + CSS — Front-end

Desenvolvemos o **Front-end da Landing Page**, responsável por apresentar o problema, a solução e a proposta do JOVI.

Utilizamos **HTML5 e CSS3**, trabalhando principalmente com:

* HTML semântico;
* CSS Grid;
* Flexbox;
* Responsividade;
* Organização e hierarquia visual.

A página foi pensada para funcionar em **desktop, tablet e mobile**.

### ⚛️ React — Sistema de Login

Também desenvolvemos uma aplicação utilizando **React**, responsável pelo **sistema de login e pela interface da aplicação**.

Nessa parte trabalhamos conceitos como:

* Componentização;
* JSX;
* Props;
* State;
* Eventos;
* Formulários;
* Validação;
* Navegação entre telas.

🚀 **Aplicação disponível online:** [Acessar o sistema](https://solucao-jovi.vercel.app/)

## 🎨 UX/UI

A experiência do usuário esteve presente durante todo o desenvolvimento.

Buscamos criar uma solução que fosse **simples de entender e fácil de utilizar**, pensando na organização das informações, navegação, hierarquia visual e adaptação para diferentes dispositivos.

Antes de partir para o desenvolvimento, trabalhamos na concepção e prototipação das interfaces para entender melhor como o usuário utilizaria a solução.
