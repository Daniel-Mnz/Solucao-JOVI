# UX Na Lente - Gerenciador Inteligente de Fotos

## Sobre o projeto

A UX na Lente é uma solução desenvolvida para auxiliar na organização de fotos capturadas por câmeras JOVI.

O sistema analisa informações associadas às fotos, como categoria e evento, e recomenda uma pasta adequada para sua organização. O usuário pode aceitar a recomendação ou escolher outra pasta.

## Funcionalidades

- Cadastro de fotos
- Listagem de fotos
- Visualização das informações de uma foto
- Recomendação automática de pasta
- Aceitar ou recusar uma recomendação
- Escolha manual de uma pasta
- Visualização das fotos já organizadas
