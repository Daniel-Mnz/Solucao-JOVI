## Instalação

1. Clone o repositório:

```bash
git clone https://github.com/Daniel-Mnz/Solucao-JOVI.git
```
2. Instale as dependências:
```npm install```

3. Execute o projeto:
```npm run dev```

4. Abra o endereço abaixo no navegador:
```http://localhost:3000```
